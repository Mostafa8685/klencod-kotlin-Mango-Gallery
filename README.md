# الاستديو (Samsung One UI Gallery)

تطبيق استديو مطابق لتصميم **استديو سامسونج (Samsung One UI Gallery)** باللغة العربية، يدعم **الوضع الفاتح والداكن التلقائي حسب الجهاز**، **قفل الاستديو بكلمة سر أو البصمة**، و**سلة المحذوفات لمدة ٣٠ يوماً**، ومبني بالكامل في ملف `MainActivity.kt` واحد متوافق مع **KlencodIDE** بدون أي مكتبات خارجية.

## المميزات الأساسية
1. **الوضع الفاتح والداكن التلقائي (Auto Light/Dark Mode)**:
   - يتعرف التطبيق تلقائياً على وضع النظام في الهاتف (`Configuration.UI_MODE_NIGHT_MASK`) ويطبق ألوان Samsung One UI للوضع الفاتح (`#F6F6F8` / `#FFFFFF`) أو الوضع الداكن الأسود (`#000000` / `#1C1C1E`) فوراً حتى أثناء عمل التطبيق، مع إمكانية التبديل اليدوي من **الضبط**.
2. **قفل الاستديو بكلمة سر أو بصمة (App Lock: PIN/Password & Biometrics)**:
   - شاشة قفل مدمجة بتصميم Samsung One UI تدعم فتح القفل عبر **بصمة الإصبع الحقيقية للجهاز** (`BiometricPrompt`) أو **كلمة السر / رمز PIN**، مع إمكانية تفعيل القفل، تغيير كلمة السر، أو قفل الاستديو فوراً من قائمة **الضبط** أو شريط الأدوات.
3. **سلة المحذوفات لمدة ٣٠ يوماً (30-Day Recycle Bin)**:
   - عند حذف أي صورة أو فيديو، يُنقل إلى **سلة المحذوفات** مع حفظ تاريخ ووقت الحذف الفعلي.
   - يعرض التطبيق عداد الأيام المتبقية لكل عنصر (مثلاً: `٣٠ يوم`، `٢٩ يوم`) ويحذف العناصر التي مرّ عليها أكثر من ٣٠ يوماً تلقائياً، مع دعم **استعادة الكل**، **استعادة عنصر**، أو **الحذف النهائي / إفراغ السلة**.
4. **واجهة استديو سامسونج الكاملة**:
   - تبويبات **الصور**، **ألبومات**، **القصص**، وقائمة **☰** المنبثقة السفلية.
   - قراءة صور وفيديوهات الهاتف عبر `MediaStore` + عارض صور كامل + محرر رسم وفلاتر + عرض الشرائح التلقائي.
